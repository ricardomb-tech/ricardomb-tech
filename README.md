### 🌱 Main Project
**Surqo — From the field to the insight**
> End-to-end platform connecting physical ESP32 sensors with generative AI to help Colombian farmers make better irrigation and fertilization decisions.
 
```
ESP32 sensor (physical) → MQTT TLS → FastAPI → Claude Haiku → Next.js Dashboard
     DHT22 · DS18B20 · Capacitive sensor · Deep sleep (10µA)
```
 
What I learned building it:
- Prompt Engineering with YAML-versioned prompts and automated evaluation (LLM-as-judge)
- ESP32 firmware with real circuit protection (TVS diodes, decoupling caps)
- Full data pipeline: sensor → broker → API → DB → frontend
- Free production deployment: Fly.io + Vercel + Supabase + HiveMQ Cloud
🔗 [View repository](https://github.com/ricardomb-tech/surqo)
🌐 [Live site](https://www.surqo.online)

### 🏡 Donde Oscar
> This website works as a complete digital marketing solution for a restaurant specializing in grilled food, addressing customer needs by offering a centralized platform that clearly showcases its menu of grilled specialties (burgers, mixed grills, and burritos) and distinguishes its two locations with unique atmospheres — making it easier for customers to decide and access the dining experience through direct information and simple contact channels.
 
```
Frontend Next.js · Backend TypeScript (Node.js) · REST API · Deploy on Vercel
```
 
What I learned building it:
- Applying clean architecture patterns with a clear separation between frontend and business logic.
- Building responsive dashboards with Next.js and reusable TypeScript components.
- Full cloud environment orchestration for the frontend (Vercel).
