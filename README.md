## 🚀 Proyectos Destacados

### 🌱 [Surqo — Inteligencia Agroclimática en Tiempo Real](https://github.com/ricardomb-tech/surqo)
> *Del surco al insight — inteligencia en tiempo real para el campo colombiano*

Plataforma **end-to-end** que conecta sensores físicos ESP32 con IA generativa para dar a agricultores colombianos insights accionables sobre riego, fertilización y salud del cultivo.

```
ESP32 (físico) → MQTT TLS → FastAPI → Claude Haiku → Next.js Dashboard
     📡 DHT22 · DS18B20 · Sensor capacitivo · ML8511 UV
```

**Stack:** `Python` · `FastAPI` · `Claude API (Anthropic)` · `ESP32/C++` · `MQTT` · `PostgreSQL` · `Redis` · `Next.js`

**Highlights técnicos:**
- 🔬 **Prompt Engineering profesional**: prompts versionados en YAML, A/B testing automático con LLM-as-judge (quality_score, latency_ms, cost_usd)
- 📊 **KPIs agronómicos**: VPD, ETc por cultivo, GDD, déficit hídrico 7 días, riesgo de plagas, score de salud del suelo
- ⚡ **Firmware ESP32**: deep sleep (240mA activo → 10µA dormido), MQTT TLS a HiveMQ Cloud, protección ESD (TVS diodes)
- 🆓 **Deploy 100% gratuito**: Render + Vercel + Supabase + Upstash Redis + HiveMQ Cloud
- 🔄 **CI/CD**: GitHub Actions con tests automáticos, build y deploy a Render/Vercel
